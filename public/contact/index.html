Reporting a bug or security issue

If you've found something that looks like a bug, a hash that doesn't match an external implementation, a password generator producing predictable output, a tool throwing errors on a particular browser, a GitHub issue is the fastest path. Include the browser and version if you can.

If you've found something that looks like a security issue, please use LinkedIn first rather than a public GitHub issue, so we can coordinate disclosure.

Privacy and GDPR requests

Data-subject requests (access, erasure, rectification, etc.) under the GDPR can be filed via the same LinkedIn channel. See the privacy notice for what data is and isn't collected. The short answer: almost none, and certainly not anything you type into the tools.
